# Smart X-Ray Luggage Detection System

AI-Powered Security Screening with Automated Threat Isolation

A real-time intelligent baggage screening platform that combines computer vision, embedded systems, hardware automation, and cloud monitoring to detect dangerous objects inside luggage and automatically initiate security responses.

---

## Key Features

- YOLOv8 Real-Time Detection
- STM32 Hardware Automation
- Conveyor Belt Control
- Solenoid-Based Threat Isolation
- Multi-Frame Threat Verification
- Cloud Logging & Monitoring
- FastAPI + PostgreSQL Backend
- Live Dashboard Access
- Emergency Stop System

## Overview

Traditional X-ray baggage screening relies heavily on human operators, which can result in delayed response times and missed threats.

This system automatically detects prohibited objects using a custom-trained YOLOv8 model and performs immediate hardware actions through an STM32 microcontroller.

Detected threats trigger:

- Conveyor Belt Stop
- Solenoid Ejection Mechanism
- Buzzer Alarm
- LED Warning Indicators
- LCD Status Updates
- Cloud Event Logging
